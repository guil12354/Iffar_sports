IFFar Sports — protótipo do painel administrativo

Arquivos:
- index.php: Dashboard
- noticias.php: listagem de notícias
- noticia-form.php: criar/editar notícia
- esportes.php: listagem de esportes
- esporte-form.php: criar/editar esporte
- include/nav.php: sidebar + topbar
- include/head.php / foot.php: estrutura comum
- css/admin.css: estilos comentados por blocos funcionais
- js/admin.js: menu mobile, inclusão/remoção/reordenação demonstrativa

O protótipo está deliberadamente desconectado do banco de dados.
Bootstrap 5.3.8 é carregado via CDN.

Para visualizar, coloque a pasta em um servidor PHP (XAMPP/MAMP/Laragon etc.) e abra index.php.
